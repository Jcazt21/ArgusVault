Bundled website and tool icons
=============================

These 50 SVG files are embedded in the program (`src/icons.rs`) and shown next to website entries
whose URL (or title) matches. Nothing is downloaded at run time.

Source:   Simple Icons, https://simpleicons.org  (npm package `simple-icons`)
Version:  16.35.0 (fetched 2026-10-16 from the jsDelivr copy of that package)
Licence:  CC0 1.0 for the collection (see LICENSE-simple-icons.txt).

          brand mark inside it is free of other terms, and that users should check per-icon
          licence data and brand guidelines.

Adding or updating an icon
--------------------------
1. Download the SVG from the pinned package version above and inspect it: it must be a single
   <svg> with one <path>, no scripts, event handlers, links or embedded images (src/icons.rs has a
   test that every file loads, and a size limit).
2. Put it here as <slug>.svg and add a line to the table in src/icons.rs (domains it stands for,
   and the names that identify it in a host label or a title).
3. Self-hosted tools (GitLab, Vault, Portainer...) are matched by a host label and must also be
   listed in SELF_HOSTED. Public sites are matched by domain only, so a lookalike host never shows
   the real site's logo.
